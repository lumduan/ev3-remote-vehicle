# เริ่มต้นที่นี่

หน้านี้จะสอนวิธีทำให้หุ่นยนต์วิ่งได้

ไม่ต้องรู้เรื่องคอมพิวเตอร์มาก่อนก็ได้ ถ้ามีคำไหนใหม่
จะมีคำอธิบายตรงที่พบคำนั้นครั้งแรก

ฉบับภาษาอังกฤษ: [START-HERE.md](START-HERE.md)

> หมายเหตุสำหรับผู้ใหญ่: ฉบับแปลนี้ยังไม่ได้ผ่านการตรวจโดยเจ้าของภาษา
> ถ้าพบประโยคที่อ่านแล้วสะดุด กรุณาแก้ได้เลย

---

## 1. อุปกรณ์ที่ต้องมี

มีสี่อย่าง

**ก้อนสมอง (brick)** กล่องสีเทาใบใหญ่ มีจอเล็ก ๆ และปุ่มหลายปุ่ม
นี่คือคอมพิวเตอร์ของหุ่นยนต์ ทุกอย่างเสียบเข้าที่นี่

**การ์ด** การ์ดความจำใบเล็กที่เสียบด้านข้างของก้อนสมอง
ในนั้นเก็บซอฟต์แวร์ที่ก้อนสมองใช้

**สาย USB** ปลายเล็กเสียบที่ก้อนสมอง ปลายใหญ่เสียบที่คอมพิวเตอร์

**จอยควบคุม** จอย Sony DualShock 4 แบบที่ใช้กับ PlayStation 4
เราจะถือจอยนี้เพื่อขับหุ่นยนต์

และต้องมี **มอเตอร์สองตัว** เสียบเข้ากับก้อนสมองด้วย

---

## 2. ใส่การ์ดแล้วเปิดเครื่อง

1. ดันการ์ดเข้าช่องด้านข้างก้อนสมองจนได้ยินเสียงคลิก
2. กดปุ่มกลมตรงกลางของก้อนสมอง
3. รอ ครั้งแรกอาจใช้เวลา **สองถึงสามนาที** ถือว่าปกติ
4. พร้อมแล้วเมื่อมีเมนูขึ้นบนจอของก้อนสมอง

> **ถ้าจอยังมืด** แบตเตอรี่อาจหมด ลองเปลี่ยนถ่านใหม่ หรือเสียบที่ชาร์จ

---

## 3. เสียบสาย

ก้อนสมองมีช่อง USB **สองช่อง** หน้าตาคล้ายกันแต่ไม่เหมือนกัน

- **ช่องเล็ก ที่อยู่ข้างช่องใส่การ์ด** ใช้ช่องนี้
- อีกช่องหนึ่งอยู่คนละด้าน ไว้เสียบอุปกรณ์เข้าหาก้อนสมอง ไม่ใช่ช่องนี้

เสียบปลายเล็กของสายเข้าช่องเล็ก แล้วเสียบปลายใหญ่เข้าคอมพิวเตอร์

จากนั้น **ที่หน้าจอของก้อนสมองเอง** ใช้ปุ่มบนก้อนสมองเลือก

```
Wireless and Networks  ->  All Network Connections
```

แล้วเปิดการเชื่อมต่อแบบมีสาย
นี่คือการบอกให้ก้อนสมองคุยกับคอมพิวเตอร์ผ่านสาย

---

## 4. เตรียมคอมพิวเตอร์

ทำครั้งเดียวพอ

**ติดตั้ง `uv`** เป็นโปรแกรมเล็ก ๆ ที่จะไปดาวน์โหลดสิ่งที่จำเป็นให้เอง
เปิด terminal ซึ่งคือแอปที่เราพิมพ์คำสั่ง แล้ววางบรรทัดนี้

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**ดาวน์โหลดซอฟต์แวร์หุ่นยนต์** ยังอยู่ใน terminal เหมือนเดิม

```bash
git clone https://github.com/lumduan/ev3-remote-vehicle.git
cd ev3-remote-vehicle
```

ครั้งแรกที่เชื่อมต่อ คอมพิวเตอร์จะถามรหัสผ่าน รหัสคือ

```
maker
```

---

## 5. เปิดเมนูตั้งค่า

คำสั่งเดียวที่ต้องจำ

```bash
uv run ev3ctl setup
```

จะมีเมนูขึ้นมา

```
  ตั้งค่าหุ่นยนต์ EV3

  มาทำให้หุ่นยนต์ของเราทำงานกันเถอะ

   >  ตรวจดูหุ่นยนต์                        ยังไม่ได้ตรวจ
      ติดตั้งโปรแกรมลงในหุ่นยนต์             ยังไม่ได้ตรวจ
      ขับหุ่นยนต์
      ใช้จอยเป็นปุ่มของหุ่นยนต์                        ปิด
      ให้ปุ่มทำงานเองอัตโนมัติ        ยังไม่ได้ตรวจ
      ดูแบตเตอรี่
      มีบางอย่างผิดปกติ - ช่วยด้วย
      ภาษา / Language                            ไทย
      ออกจากโปรแกรม

  ลูกศรขึ้นลง เลือก   Enter ตกลง   q ออก
```

ใช้ **ปุ่มลูกศรขึ้นและลง** เพื่อเลื่อน กด **Enter** เพื่อเลือก
กด **q** เพื่อออก

ถ้าอยากอ่านภาษาอังกฤษ ให้เลือก **ภาษา / Language**

---

## 6. ทำสองอย่างนี้ ตามลำดับ

**อย่างแรก เลือก "ตรวจดูหุ่นยนต์"**

โปรแกรมจะตรวจทีละอย่าง แล้วบอกว่ามีอะไรผิดปกติ
ถ้าเจอปัญหาจะหยุดตรงนั้น และบอกว่าต้องไปแก้อะไร
แก้แล้วเลือกตรวจใหม่อีกครั้ง

ถ้าทุกอย่างเรียบร้อย โปรแกรมจะบอกเอง

**อย่างที่สอง เลือก "ติดตั้งโปรแกรมลงในหุ่นยนต์"**

เป็นการคัดลอกโปรแกรมขับเข้าไปในก้อนสมอง
เพื่อให้ทำงานได้เองโดยไม่ต้องต่อคอมพิวเตอร์
ทำครั้งเดียวพอ และทำใหม่เมื่อซอฟต์แวร์มีการเปลี่ยนแปลง

---

## 7. ปลุกจอยให้ตื่น

กดปุ่มกลม **PS** ตรงกลางจอย

ไฟด้านหน้าจะติดและค้างอยู่ แปลว่าจอยคุยกับก้อนสมองได้แล้ว

> **ถ้าไฟกะพริบสีขาวไม่หยุด** แปลว่าแบตจอยหมด ให้เสียบที่ชาร์จ
> ชาร์จไปเล่นไปได้

---

## 8. ขับกันเลย

**ยกล้อให้ลอยจากโต๊ะก่อน** ถือไว้ในมือหรือวางบนหนังสือ
หุ่นจะได้ไม่วิ่งหนีตอนที่เรากำลังหัด

เลือก **ขับหุ่นยนต์** จากเมนู

รอสักครู่ ก้อนสมองเริ่มโปรแกรมค่อนข้างช้า

| สิ่งที่เราทำ | สิ่งที่เกิดขึ้น |
| --- | --- |
| ดัน **ก้านซ้าย** ไปข้างหน้า | ล้อทั้งสองเดินหน้า |
| ดึงกลับมาข้างหลัง | ล้อทั้งสองถอยหลัง |
| ดันไปซ้ายหรือขวา | หุ่นหมุนอยู่กับที่ |
| ดันไปข้างหน้าเฉียงข้าง | หุ่นเลี้ยวเป็นวงโค้ง |
| ปล่อยมือ | หุ่นหยุด |

**กด L1 ค้างหนึ่งวินาทีครึ่ง** เพื่อเปลี่ยนความเร็ว
ไฟบนก้อนสมองจะเปลี่ยนสีบอกว่าตอนนี้ความเร็วไหน

| สีไฟ | ความเร็ว |
| --- | --- |
| เขียว | ช้า เริ่มที่นี่ |
| ส้ม | ปานกลาง |
| แดง | เร็ว |

**กด R1** เพื่อดูแบตเตอรี่

**กด Share** เพื่อหยุดโปรแกรม

---

## 9. ใช้จอยเป็นปุ่มของหุ่นยนต์

เลือก **ใช้จอยเป็นปุ่มของหุ่นยนต์**

ตอนนี้จอยจะควบคุมเมนูของก้อนสมองได้ ไม่ต้องวางหุ่นลงเลย

| ปุ่มบนจอย | ทำอะไร |
| --- | --- |
| ปุ่มลูกศร | เลื่อนขึ้นลงในเมนูของก้อนสมอง |
| **X** | เลือกสิ่งที่ชี้อยู่ |
| **Share** | ย้อนกลับ และหยุดโปรแกรมที่กำลังทำงาน |

จะได้ยินเสียงคลิกเบา ๆ ทุกครั้ง เพื่อบอกว่ากดติดแล้ว

เลือกเมนูเดิมอีกครั้งเพื่อปิด

---

## 9b. ให้ปุ่มเริ่มทำงานเอง

เราสั่งให้หุ่นยนต์เปิดปุ่มจอยให้เองทุกครั้งที่เปิดเครื่องได้
จะได้ไม่ต้องทำข้อ 9 อีก แค่เปิดหุ่นยนต์แล้วกดปุ่ม PS

เลือก **ให้ปุ่มทำงานเองอัตโนมัติ** ในเมนู

ขั้นตอนสุดท้ายต้องให้ผู้ใหญ่ช่วย **ครั้งเดียวเท่านั้น**
เมนูจะแสดงบรรทัดที่ต้องพิมพ์ให้เห็นชัด ๆ

```bash
sudo loginctl enable-linger robot
```

เครื่องจะถามรหัสผ่าน รหัสคือ `maker`

บรรทัดนี้อนุญาตให้หุ่นยนต์เริ่มโปรแกรมของเราได้ก่อนที่จะมีใครล็อกอิน
หลังจากนี้ไม่ต้องรบกวนผู้ใหญ่อีกเลย

เมื่อทำเสร็จ กด Enter แล้วเมนูจะตรวจให้ว่าสำเร็จหรือยัง

หลังจากนี้ ทุกครั้งที่เปิดหุ่นยนต์ ให้รอประมาณครึ่งนาที แล้วกดปุ่ม PS
ปุ่มต่าง ๆ จะทำงานได้เลย การรอครึ่งนาทีถือว่าปกติ
เพราะหุ่นยนต์ตื่นช้า

---

## 10. เมื่อมีอะไรผิดปกติ

ห้าอย่างนี้เป็นสาเหตุของปัญหาเกือบทั้งหมด ลองไล่ตามลำดับ

**1. สายหลวม** เสียบให้แน่นทั้งสองด้าน ข้อนี้พบบ่อยที่สุด

**2. ก้อนสมองปิดอยู่** กดปุ่มกลาง แล้วรอจนขึ้นเมนู

**3. จอยหลับอยู่** กดปุ่ม PS กลม

**4. แบตจอยหมด** เสียบที่ชาร์จ ชาร์จไปใช้ไปได้

**5. สายมอเตอร์หลวม** หุ่นยนต์ต้องมีมอเตอร์สองตัวจึงจะขับได้

ยังไม่หาย เลือก **มีบางอย่างผิดปกติ - ช่วยด้วย** ในเมนู
จะแสดงรายการนี้ และกด **d** เพื่อดูรายละเอียดทางเทคนิคสำหรับผู้ใหญ่

## คำที่อาจยังไม่รู้จัก

**Terminal** แอปที่เราพิมพ์คำสั่งให้คอมพิวเตอร์

**คำสั่ง** บรรทัดที่เราพิมพ์ใน terminal แล้วกด Enter

**ก้อนสมอง (brick)** กล่องสีเทา คือคอมพิวเตอร์ของหุ่นยนต์

**Brickman** เมนูที่อยู่บนหน้าจอของก้อนสมอง

**จอย (gamepad)** สิ่งที่เราถือไว้เพื่อขับ

**โปรแกรม** ชุดคำสั่งที่ก้อนสมองทำตาม
